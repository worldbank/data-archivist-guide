# 1. Introduction

This *Quick Reference Guide for Microdata Archivists* provides data archivists with guidelines to document a micro-dataset in compliance with The Data Documentation Initiative Codebook ([DDI Codebook/DDI-C](https://ddialliance.org/ddi-codebook)) and The Dublin Core Metadata Initiative ([DCMI](https://www.dublincore.org/specifications/dublin-core/dcmi-terms/)) metadata standards[^1]. 

This Guide summarizes the process in 7 chronological steps:

1.  Organizing the folder structure
2.  Gathering and preparing the data set
3.  Gathering and preparing the documentation
4.  Documenting the study, data file(s) and variables
5.  Documenting external resources
6.  Quality assessment
7.  Generating the output for publication

This guide introduces the key concepts, metadata standards, and best practices for documenting survey microdata and related resources. Where appropriate, it provides links to the [Metadata Editor](https://worldbank.github.io/metadata-editor-docs/) for detailed guidance on implementing these practices using the Metadata Editor.

While examples may reference the Metadata Editor, this guide is primarily focused on metadata standards and documentation practices, rather than the operation of the tool itself. It should not be considered a Metadata Editor training manual or reference guide. Users are assumed to have a basic familiarity with the Metadata Editor and its functionality.

Comprehensive instructions on installing, configuring, and using the Metadata Editor are available in the [Metadata Editor Documentation](https://worldbank.github.io/metadata-editor-docs/).

[^1]: DDI-Codebook (DDI-C) and DCMI (Dublin Core Metadata Initiative) are international XML metadata specifications. For more information on these standards, please visit https://ddialliance.org/ddi-codebook and https://www.dublincore.org/specifications/dublin-core/dcmi-terms/.
