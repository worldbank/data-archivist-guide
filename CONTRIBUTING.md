# CONTRIBUTING

Thank you for considering contributing! We appreciate your interest in helping us improve this project.

## How Can I Contribute?

- **Bug Reports:** Open an issue with details to help us reproduce the problem.
- **Feature Requests:** Open an issue describing the feature and its use case.
- **Pull Requests:** Fork the repository, create a branch, make changes, and open a PR.

## Contributing Code

1. Fork the repository.
2. Create a descriptive branch: `feature/...` or `bugfix/...`.
3. Make changes and add tests where appropriate.
4. Commit with clear messages and push to your fork.
5. Open a pull request and reference related issues.

## Code of Conduct

Please follow the project's [Code of Conduct](CODE_OF_CONDUCT.md).
